# rust-cli-todo
## システムの説明 (アーキテクチャ)

本アプリケーションは、Rustの型システムと所有権モデルを活かして安全に動作するように設計されています。

*   **Enumベースのコマンドパーサー:**
    ユーザー入力を直接処理するのではなく、一度 `Command` 列挙型にパース（変換）する設計を採用しています。これにより、不正な入力や引数不足に対するエラーハンドリングをパーサー層に集約し、メインロジックの安全性を担保しています。
*   **論理削除 (Soft Delete) の採用:**
    タスクの削除（`del`）を実行した際、配列（`Vec<Task>`）から要素を物理的に削除するのではなく、内部的に `deleted: bool` フラグを `true` にする論理削除を採用しています。これにより、削除時のインデックスのズレやパニックを完全に防ぎ、安全なデータ操作を実現しています。
*   **インメモリ管理:**
    現在のバージョンでは外部ファイルやデータベースを使用せず、すべての状態をメモリ上で高速に処理します。

## セットアップ

Rustの開発環境（Cargo）がインストールされている必要があります。

```bash
# リポジトリのクローン
git clone https://github.com/sin-45/rust-cli-todo.git
cd rust-cli-todo

# アプリケーションの起動
cargo run
```

## 操作方法 (コマンド一覧)

アプリを起動すると `> ` というプロンプトが表示され、入力待ち状態になります。以下のコマンドを入力して操作します。

| コマンド | 説明 | 使用例 |
| :--- | :--- | :--- |
| `add <タスク名>` | 新しい未完了タスクを追加し、IDを発行します。 | `add 競技プログラミングの復習` |
| `list` | 現在の**未完了タスク**を一覧表示します。 | `list` |
| `list -all` | 完了済みのものも含めた**すべてのタスク**を表示します。（※削除済みのものは表示されません） | `list -all` |
| `done <title>` | 指定したIDのタスクを「完了済み `[x]`」にします。 | `done 1` |
| `del <title>` | 指定したIDのタスクをリストから論理削除（非表示に）します。 | `del 2` |
| `exit` | アプリケーションを終了します。 | `exit` |

### 実行例

```text
$ cargo run
ToDoアプリを起動しました。
コマンド: add <テキスト>, list, done <ID>, del <ID>, exit

> add 牛乳を買う
タスクを追加しました: [ID: 2]
> done 1
タスク 1 を完了にしました。
> list
[ ] ID:2: 牛乳を買う
> list -all
[x] ID:1: 宿題を終わらせる
[ ] ID:2: 牛乳を買う
> exit
終了します。
```
